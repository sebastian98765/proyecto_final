# Lista de verificación de entrega — HotelUQ

- [ ] Abrir `hoteluq/pom.xml` como proyecto Maven en IntelliJ.
- [ ] Confirmar que IntelliJ utiliza JDK 21.
- [ ] Ejecutar `mvn clean test` y guardar evidencia del resultado.
- [ ] Ejecutar `mvn javafx:run`.
- [ ] Iniciar sesión como cliente y verificar una reserva y la tarjeta virtual.
- [ ] Iniciar sesión como administrador y verificar reportes y exportación TXT.
- [ ] Revisar `README.md` y los diagramas `docs/uml/*.puml`.
- [ ] Crear manualmente la rama del séptimo avance, hacer commit y push.
- [ ] Confirmar en GitHub que los archivos de documentación están publicados.

**Nota:** no se incluye el directorio `.git` en el ZIP de entrega. Los commits y el push se hacen desde el repositorio local del estudiante.
